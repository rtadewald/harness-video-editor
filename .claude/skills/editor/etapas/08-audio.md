# 08 · Áudio

A cadeia é do app (voz limpa → passa-altas → timbre → compressor; sons dos presets e das transições; fundo 11 dB
abaixo da voz, com ducking; −14 LUFS). Você escolhe a **trilha de fundo** pelo clima do vídeo.

> **Antes, leia `../aprendizados/audio.md`.**

```bash
A travar <id> audio
A trilhas                                   # TRI-…: clima e BPM
A audio <id> --fundo <TRI-… | id | nenhum> [--limpeza leve|media|forte] [--timbre natural|quente|clara]
```

Tutorial/ferramenta → `lofi-piano`, `chillhop` ou `arpejo-suave`; notícia de IA → `sinos-leves` ou `grave-tech`; opinião
forte → `cinematico`. Varie entre vídeos seguidos. Nunca a limpeza "isolamento" (paga) sem Rodrigo pedir.

Tempo esperado: segundos.
