# 07 · Transições

O padrão vem das **favoritas de Rodrigo por par de grupos** (Full ator · Tela dividida · Tela cheia; página
Transições do app). Use a função do app:

> **Antes, leia `../aprendizados/transicoes.md`.**

```bash
A travar <id> transicoes
A transicoes-variar <id>          # cada corte com uma das favoritas do par, meio a meio; nunca três efeitos seguidos
```

À mão (raro): `A transicoes-definir <id> <plano que entra> <TRA-… | id | padrao>` — para dar peso a uma virada do vídeo
(`brilho-branco`, `zoom-desfoque`) ou limpar excesso. Os cortes que Rodrigo trocou à mão ficam.

Tempo esperado: segundos.
